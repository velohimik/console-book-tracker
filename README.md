# Console Book Tracker

## Description

Console application for managing your books. I developed it during the Java study. The book list is stored in the memory. User can interact with the app in the terminal with simple console menu 

## Run

1. Execute ```make.sh``` in the root for compiling and packaging.
2. Execute ```run.sh``` in the root for running the app.
3. Use the app according to the instruction in the terminal.

## Functionality

- add a new book with title, author and year of publication;
- look at the list of all user's book;
- get the information of one specific book by book's id.
